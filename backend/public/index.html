Reports

Attendance Report

P = full day (shift completed) · HD = half day (worked minimum half-shift hours) · A = absent or punched in without punching out · W/O = Sunday weekly off · — = before Date of Joining

Employee Punch Time Report

Har employee ke har punch-in / punch-out ka pura log — date, on duty/off duty time, location, working hours (same data jo Attendance Log tab se milta hai).

Employee Data Report

Downloads full employee master data — ID, name, designation, project, shift category, zone, ward, site code, phone, location, DOJ, status.

Shift Cycle Report (8 Hrs - FA)

Sirf 8 Hrs - FA shift category ke employees ke liye — har on-duty (login) punch ke time se pata karta hai woh Morning (7–8 AM login), Afternoon (3–4 PM login), ya Night (11 PM–12 AM login) shift thi. Location column employee ki us punch ki live location hai (jo pehle se profile mein feed hai wo nahi), aur Count batata hai ki usi date + usi live location + usi shift mein kitne employees on-duty the.

Employees

Manage Projects

Har employee ko ek Project assign karo (MTDC, MCGM HK, MCGM, Security, MCGM Education, Others, ya apna naya project add karo). Har project ka apna Weekly Off day bhi set kar sakte ho — zaroori nahi ki sabka Sunday ho. Do ya zyada projects ko same Group Name dene se woh ek combined group ban jaate hain (jaise MCGM) — group ke andar bhi har project ka data alag hi rehta hai, sirf navigation/access combine hota hai.

Manage Shift Categories

Duty hours ke hisab se category banao (jaise 12 Hrs - HK, 8 Hrs - FA, 9 Hrs - General). Half Day auto = Full Hours ka aadha, ya khud daal do.

Select a Project

Employee section ab project-wise separate hai — niche list se ek project chuno, uske employees uss project ke andar hi milenge.

Add New Employee

Salary fields are optional — leave blank if you'd rather set them later from the Employees list.

Bulk Add Employees

Add many employees at once — upload an Excel/CSV file, or paste rows directly. Duplicate Employee IDs are skipped automatically.

Expected column headers (any order, case-insensitive): Employee ID, Name, Designation, Phone, Location, DOJ, Project, Shift Category. Optionally also Zone, Ward, Site Code, and Basic Salary, HRA, Other Allowances, Deductions, PF, ESIC — if included, these are only applied to newly-added employees (existing employees are never overwritten). (DOJ as YYYY-MM-DD, Shift Category as exactly the category name shown in "Manage Shift Categories", e.g. "12 Hrs - HK"). Only Employee ID and Name are required.

Column order for pasted rows: Employee ID, Name, Designation, Phone, Location, DOJ, Project, Shift Category, Zone, Ward, Site Code, and optionally Basic Salary, HRA, Other Allowances, Deductions, PF, ESIC (leave later columns blank if not needed).
